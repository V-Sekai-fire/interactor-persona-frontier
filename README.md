# skill-look-dev-character-persona-stack

A Hermes skill that maps the look-dev to game character-persona pipeline onto our repositories and grades each stage against the Bitter Lesson.

## What it is for

Finding which repository owns a character stage (body fit, auto-rig, garments, motion, face, persona, runtime), and deciding whether a proposed component is on the scaling path or is hand-written content with a retirement trigger. The stage table and verdict are in `references/stack.md`; the five-owner repository survey is `references/repo-inventory.md`.

## Build and run

```
git clone https://github.com/V-Sekai-fire/skill-look-dev-character-persona-stack ~/.hermes/skills/game/look-dev-character-persona-stack
```

```
skill_view(name="look-dev-character-persona-stack")
```
